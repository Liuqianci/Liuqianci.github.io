# 基本厨具

+ 锅具
  + 炒锅：万能的，煎炒烹炸样样精通；
  + 汤锅：用于煮面条或者烧水；
  + 平底不粘锅：用于煎饼、煎肉；
  + 小奶锅：做快手菜
+ 菜刀
  + 切刀：刃薄，锋利，适合切菜；
  + 砍刀：刃厚，稍微钝，适合砍骨头；

# 家中必备调理

+ 生抽
+ 陈醋
+ 油
+ 大蒜
+ 生姜
+ 淀粉
+ 鸡精
+ 味精
+ 盐

以上9个调料可以应付80%的家常菜。可以适当添加以下几种扩充：

+ 料酒
+ 豆瓣酱
+ 干辣椒
+ 白糖
+ 胡椒粉

# 认识盐

&emsp;&emsp;盐是百味的基础，做菜时别的调料可以不放，但绝对不能少了盐。放盐的原则：**宁少勿多**！！

## 煎鸡蛋

1. 碗中打入两个鸡蛋，**加入适量食盐**，一个鸡蛋就是一个小指甲盖那么多的盐；
2. 用筷子把鸡蛋打散。左手拿碗可以稍微向右手倾斜，不容易撒出去。打10多秒即可，目的是让蛋清和蛋黄混在一起；
3. 开火，把锅中水分烧干；
4. 倒油，用油把锅底润一下；
5. 油冒烟后，倒入鸡蛋；
6. 鸡蛋蛋清凝固后记得用锅铲捅破，让里面蛋黄流出来，否则里面煎不到；
7. 蛋液定型后翻面，一面不要煎太久，多操作几次，两面金黄即可捞出；

注意，油少或者油温过高，容易煎糊；油温太低，煎出的蛋不够松软。


## 荷包蛋

1. 小火，倒入少许的油；
2. 油在微微冒烟时，打一个鸡蛋下去，让鸡蛋在油里慢慢的煎，等定型（边缘变的焦黄）后翻面；
3. 撒上少许盐，倒在手掌上分开撒，再翻面；
4. 多翻面，让每一面都接触到盐，然后盛出；

&emsp;&emsp;喜欢溏心蛋的可以少煎一会或者只煎一面，不过从营养学的角度来说不建议吃溏心蛋，溏心蛋没有熟，不利于人体吸收。全熟蛋杀菌效果更彻底，更利于健康。

# 味精与鸡精

&emsp;&emsp;鸡精和味精主要用于调味，放很少一点就可以成倍的提升菜品的口味。不过很多人认为鸡精和味精有害，尤其是味精在加热到120度后会生成焦谷氨酸钠，可能致癌。但有论文指出适量吃鸡精和味精都是安全的。只需要注意味精温度过高会失去鲜味，所以只在出锅前加味精。


## 炒空心菜——味精和鸡精的运用

1. 择菜——把食材处理的长短大小统一，方便食用，方便烹饪；把叶子都摘下来，如果空心菜不是很老，那么根部也可以留着，只要用指甲掐一下根部，能掐动就代表还不老；
2. 洗菜，把泥沙充分洗掉，淘洗就行，不要用手搓；洗完用滤网捞出来；
3. 开火，直接开最大的火，把锅里水烧干；
4. 倒油，对于铁锅来说宁多勿少防止炒糊；
5. 油开始冒烟后倒入蔬菜，动作一定要快，用菜把油盖住防止砰溅；绿叶菜很容易熟，所以需要经常的翻炒，每隔几秒钟就翻炒一下；这个就看火大小，火大勤翻炒，火小慢翻炒；
6. 叶子快蔫掉时代表快熟了，此时放调料，放入盐、鸡精、味精，撒开一点。盐要多放一点（因为蔬菜的水多），鸡精和味精用量是盐的1/4~1/5即可，鸡精可以更少；放入调料后疯狂翻炒，让调料均匀；

> 鸡精和味精一起使用有1+1>2的效果。

> 用旺火炒菜的原因：用旺火炒菜更好吃，且蔬菜中有很多的维生素被加热后容易流失，所以用旺火炒菜可以尽快的出锅。


# 炒菜的第一个公式

`油+菜+盐+鸡精\味精 -> 出锅。`先把油烧热，放入菜，菜快熟的时候放入盐、鸡精、味精，把调理和匀就可以出锅了。至少80&#37;带叶子的蔬菜都可以这么做。

翻炒时注意，如果菜的茎叶比较厚实，类似白菜，就可以适当减少翻炒的频率。

放调料的时候可以先放到锅铲上，这样可以控制用量，也方便和均匀。

根据经验来看，有些蔬菜含水量很大，炒菜后的汤水会很多，这时候要么选择把汤汁倒掉，要么就多放盐。

# 干辣椒、大蒜、花椒

干辣椒、大蒜、花椒也属于调料的范畴，不过他们是土里长出来的天然调料，一样可以增加食品的风味。这三个是川菜中的三剑客，经常形影不离。

新手炒菜容易把这些配料炒糊，因为油温太高了。在熟能生巧之前，可以在放入油后立马下锅配料。

## 炒菜苔

&emsp;&emsp;菜苔择菜的时候需要一点小技巧，用一把刀从根部切十字，第一刀切到第二片叶子的位置，第二刀切到第三片叶子的位置。然后从第三片叶子稍微往上一点的地方切掉，这样就是一个十字花刀的形状，方便炒熟也方便入味。剩下的部分很细，切一刀就可以了。菜苔上有花的话把花去掉，口感不好。如果买来的菜苔根部很老的话，还需要先去根部的皮。

&emsp;&emsp;一盘菜用三颗大蒜，三个干辣椒，几粒干花椒：

+ 用到把干辣椒切成一厘米长的段；
+ 大蒜剥皮，剥皮最快的方法就是用菜刀拍。然后把大蒜切成片。

炒菜步骤：

1. 烧半锅水，水开后把菜苔焯水（菜苔的茎太厚了，不好炒，需要提前焯水），煮1分钟到1分半即可，不要太久，否则就不脆了；
2. 把菜苔倒入滤网中，用冷水冲，可以保持爽脆口感；
3. 锅烧干后倒油，然后马上放入准备好的干花椒、干辣椒；看到干辣椒微微发黑的时候放大蒜，然后立即放入准备好的菜；
4. 提前焯水后菜基本已经熟了，所以翻炒片刻就可以放盐、味精、鸡精，和匀后出锅；

&emsp;

### 手撕莲白

洋葱、大白菜、卷心菜等都需要去掉外边1到2层，之地很老，卖相差，口感也不好。

然后把莲白一层一层的拨下来，每一片叶子在随意撕成片。手撕的比刀切的好吃，因为手撕的断面不整齐，更容易入味。只要叶子部分，菜帮子可以丢掉。撕完之后清洗滤水。

依旧准备大蒜、干辣椒、干花椒。莲白菜不需要焯水。

&emsp;

### 素炒四季豆

四季豆的挑选：粗壮的四季豆口感稍微老，但是四季豆味道足，缺点是筋多；细长的四季豆口感更细嫩。挑选时看表面有没有黑点或者坑坑洼洼的，这可能被虫子咬过。

四季豆比较耐放，在冰箱中放7~10天没问题。

四季豆择菜时要把两侧的筋去掉，从头部的尖开始，逆着尖使劲往后一拉就行，然后把尾巴掐下一点，逆着把另一侧筋去掉。两侧筋都去掉后，把四季豆恰成5厘米左右的段，这时中间一些没有去掉的筋就露出来了，可以去掉。

四季豆没有泥沙，清洗时使劲拿手和一下就行。

素炒四季豆的配料，可以准备2&#45;3瓣大蒜切片。还有一个秘密武器：留兰香（食用薄荷），取顶端的部分，掐5&#45;6根左右，用刀稍微切碎即可。

生的四季豆吃了会引起食物中毒，所以四季豆的做法要分两步：先制熟，然后回锅调味。

在饭店里制熟四季豆，用的是大量热油，又快又好吃，但是家里这样做太浪费了。家里比较经济实惠的方法就是用水煮，把四季豆放入锅中，加水，水要稍微没过四季豆。盖上盖子大火烧开，然后转中火再煮5~10分钟。出锅后用凉水冲一下口感更佳。

剩下的步骤很简单：大火烧干锅，放油、放入大蒜，放入四季豆翻炒。不过四季豆很难入味，所以需要更早的时候放入盐，然后再翻炒两三分钟。最后调为中火再煎两三分钟。出锅前放入鸡精、味精、食用薄荷，翻炒几秒把薄荷炒到打蔫即可出锅。

豇豆、扁豆都可以用这个方法来做。


# 火候

炒菜中火候是个动态的概念，菜到了不同的时候会用到不同的火候。炖鸡的时候先大火烧开然后小火慢炖；红烧肉先大火烧开转小火慢炖最后大火收汁。

家用燃气灶可以分为四个挡位：

1. 燃气灶打开后直接拧到最后，火最小但不会熄灭，这个就是1档，炖汤、放调料、煎蛋时会用到这个档位；
2. 往回拧，外环稍稍有一点火焰，这个就是二档，一般在炖煮、蒸菜的时候会用到；
3. 继续往回拧，外环火焰加大，这个就是三档，一般炒菜时使用；
4. 拧到最中间，火焰最大，就是第四档，火力全开模式，炒菜或需要把水烧开时使用。


# 养锅

炒菜的锅就只用来炒菜，不要用来烧水或炖汤，这样铁锅表面就会一直有一层油膜。有了这层膜，铁锅就成了天然的不粘锅。油膜不怕清洗、不怕洗洁精，但就是怕水。

## 葱油饼

做个葱油饼，看看铁锅是否能不粘。

原料：免费、盐、鸡蛋、葱花。一般2勺面粉搭配一个鸡蛋。

1. 盆中放入面粉，再放入一点盐，面粉加清水和匀。
2. 把干面粉全部和湿后加入鸡蛋和匀。一定要先加水后加鸡蛋，否则面粉容易起球，很难和均匀。
3. 鸡蛋、面粉和匀后加入葱花，继续和匀。可以再加点水，只要可以用筷子蘸起来后可以轻松滴下去就可以了。
4. 用二档小火（之后全程小火）锅烧干放油，让油在锅周围绕一圈，防止之后粘锅；
5. 放入准备好的面。新手可以从1勺开始尝试，放入面越多难度越大。让面绕着锅溜一圈，成一个圆形。先不要动，调整以下让饼定型。
6. 定型后抖动铁锅，让饼从铁锅上脱落；如果锅保养的不好那么就粘锅了，此时可以往周围滴几滴油。用锅铲把饼弄下来。
7. 可以晃动铁锅，让饼在锅内滑动受热均匀。听到沙沙的声音就可以翻面了。每翻一次煎一分钟即可，翻2、3次。每面都煎到金黄后可以出锅。



&emsp;

铁锅用完一定要擦干，防止里面有水，否则很容易生锈。

# 调料分类

## 油

食用油算不上调料，但却是不可缺少的部分。日常可以换着花样用油，我们人体需要从吃到的油脂中获取单不饱和脂肪酸、多不饱和脂肪酸、饱和脂肪酸，长期单一的吃某一种油不能满足身体的需要，所以可以换着花样吃，这次买大豆油，下次就买花生油。

动物性油脂也是重要的油脂来源。

## 盐

盐是百味之首，也是百味的基础。买盐要看标签。一般我们吃的是“加碘食盐”。标识“腌制用盐”一般用来腌制咸菜泡菜。还有的盐会标注“粗盐”或“大粒盐”，这种盐颗粒比较大，不容易溶解，不适合家中炒菜。

## 味精

味精用来提升菜品的鲜味。一般要买标注“99%味精”的味精，意思是谷氨酸钠含量达到99%。

## 鸡精

主要成分还是味精，因为加了风味物质，吃起来有鸡肉味。鸡精的鲜味需要热量激发，所以用在热菜中。

## 酱油

黄豆酱油、红烧酱油、生抽、老抽、味极鲜、蒸鱼豉油都属于酱油，只是因为配料和酿造工艺不同所以有了不同的风味和口感。可以只买一瓶生抽，老抽的主要作用是上色。

## 醋

分为陈醋和白醋。

陈醋各个城市的主要品牌不同。陈醋分为各个等级，比如特级、一级、二级等等，差别在于总酸度，酸度越高表示酸味越浓，特技最酸，依次递减。

白醋也叫米醋，这种醋就是纯粹的酸，是煮酸菜鱼的必备调料。买白醋看度数，度数越高醋越酸。度数其实就是表示乙酸浓度，6度醋就是每100ml含有6g乙酸，没有标度数的就看配料表。

## 料酒

料酒的作用就是去腥。好的料酒应该起到去腥增香的作用。含有黄酒、香辛料等成分的料酒都是不错的选择。

## 耗油

买海天的就行。耗油就是一个辅助性质的存在，味道像生抽，但是比生抽更淡。耗油的鲜味和鸡精一样需要热量激发，所以一般用在热菜汤中。

## 豆瓣酱

买豆瓣酱看产地，要是四川郫县产的。其次看上面的油色，颜色红亮为上品。然后看颜色，好的豆瓣酱色泽红润不暗淡。

## 鲜花椒油/藤椒油

鲜花椒是一种比较难获得的原料，所以一瓶保留了鲜花椒滋味的鲜花椒油/藤椒油就是家里不错的选择。藤椒油和鲜花椒油的区别在于，藤椒油清香，鲜花椒油麻味更足。

## 芝麻油

芝麻油是一种很好的火锅蘸料。一些菜放入芝麻油可以让口味变的更醇厚。购买时看配料表，最好选择纯芝麻压榨的，不要买食用油和芝麻油调配的。

## 干花椒

干花椒分为红花椒和青花椒，青花椒又叫麻椒。红花椒突出香味，青花椒有独特的麻香味。家里选择青花椒即可。

## 花椒粉

如果讨厌吃到大颗粒的干花椒，那么可以用花椒粉替代。买的时候要看配料表，应该只有花椒才行。

## 白胡椒粉

注意是白胡椒粉。黑胡椒一般用于西餐。白胡椒粉是去腥神器，做各种肉类鱼类菜肴都可以用到。买的时候要看配料表只有白胡椒才行。

## 干辣椒

市面上的干辣椒品种繁多，并不是所有干辣椒都适合拿来炒菜。建议购买“新一代”干辣椒，名字就叫“新一代”，一般超市都难看到。卖辣椒窍门：个小的比个大的辣，个细的比个粗的辣。

## 桂皮、八角

八角又俗称大料。桂皮和八角这两种香料都非常适合拿来炖肉，可以使肉类菜肴去腥解腻。一般两种香料同时使用。

## 陈皮

陈皮就是经过特殊处理的橘子皮。功能是去腥、除膻、增香、解腻、开胃。煮牛羊肉的时候丢一块进去，汤鲜肉香。

## 红薯粉

新手可以简单的把超市里买到的嫩肉粉、红薯粉、生粉、玉米淀粉、土豆淀粉等看作是一个东西。他们都属于淀粉，作用都是让肉质变得鲜嫩。新手只需要用好这一个特性即可。

## 白糖

白糖在一些糖醋类菜肴中会用到。

## 白芝麻

白芝麻可以用来做辣椒油，或者给菜品做点缀。也有增香的作用。白芝麻分为去皮白芝麻和没有去皮的白芝麻。要注意生的白芝麻不香，需要炒熟之后才香，突出芝麻味。凉菜、起锅后放芝麻的菜用熟芝麻，需要芝麻和食材一起过油炸或者炒的菜用生芝麻。

## 十三香

一些麻辣干香的菜品中会用到。

## 孜然粉

孜然粉就是用于烧烤的。

## 生姜

去腥增香的神器。可以选择个头大的洗干净的生姜，虽然理论上来说个头小的更香，但是清洗太麻烦了。炒肉、炖鱼的时候放一点生姜准没错。

姜还是老的辣，家里的姜一般都是老姜，只有老姜才有比较好的去腥增香效果。与之对应的是仔姜，只在特殊的菜中才会用到。

## 大蒜

大蒜也是去腥增香的神器。大蒜品种很多，买普通的就行。大蒜买回来放冰箱保鲜室保存防止发芽。

## 小葱

小葱也有去腥增香的作用，一般用于汤菜、肉菜中。

## 大葱

大葱也是去腥增香，尤其是去腥效果非常强，煮鱼的时候可以放两根。因为其爽脆鲜嫩的口感，也可以当配菜使用。

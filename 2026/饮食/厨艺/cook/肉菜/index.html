四、各种肉菜

本文字数： 5k

猪肉怎么买

  买肉不需要记住什么前腿肉、后腿肉、二刀肉、梅花肉，只需要记住我们是要瘦肉还是肥肉就行。纯瘦肉的价格很贵，瘦肉多肥肉少的肉性价比很高。

  如果炒肉总是很柴，可以试试有明显脂肪纹理的肉，这种肉炒出来更鲜嫩，对新手很友好。这种肉就是夹子肉/二刀肉。优点是价格便宜、性价比高；同时可以买到瘦肉和肥肉，一肉两用；带脂肪纹理的肉不容易柴。这种肉挑选时看瘦肉占比越多越好。但这种肉的缺点是需要和肥肉一起买，不喜欢吃肥肉的话会浪费；肉形不规整，切出来的肉丝炒的时候很容易碎，不适合用来切肉丝。

  不在意价格想吃纯瘦肉的话，可以买散切的瘦肉，挑选方法也一样：有脂肪纹理的适合炒肉片；如果想切肉丝，就挑选一块四四方方的净瘦肉，比较好操作。

  炒菜不建议用里脊肉，虽然里脊肉四四方方的看起来很漂亮，但处理不好很容易柴。但里脊肉很规整，很适合切肉丝。里脊肉还分大里脊和小里脊，看粗细就行，小里脊肉质细嫩，怎么做都好吃。

  五花肉是很常用的肉，这种肉有很明显的肥瘦纹理，是做回锅肉、红烧肉、梅菜扣肉、粉蒸肉最理想的食材。买五花肉的时候也是尽量挑瘦肉多且纹理清晰的部分。

   排骨尽量买一条一条的中排，散装砍好的价格会便宜一点，但骨头大肉少，口感相对差一点，尽量挑选骨头小肉多的。

  猪腿肉一般会买猪后腿，因为肉比较多，瘦肉占比高。猪前腿去掉骨头后，肉就很少了，根本不够吃。猪腿的骨头非常硬，买的时候让摊贩砍好了再带回家。

  

  肉买回家后，不要直接放冰箱，先清洗，分成小份。有些地方的摊贩在卖肉的时候会烧猪皮，这样可以去除残留的猪毛。如果购买的时候没有这个服务，猪皮上还残留有猪毛，可以把锅烧烫，然后把猪肉放进去滋啦几下，把肉皮烫的金黄起皱，上面的毛就没了；再用热水清洗猪肉，然后用刀刮猪毛（或者拿钢丝球刷，不过要注意钢丝球容易断）。清洗完成后分块。先把瘦肉从上面剔下来，纯瘦的部分可以用来炒或者煮汤，肥瘦的部分可以用来做回锅肉，也可以直接切成片炒着吃。之所以要切成小块是因为方便解冻，如果一大块肉放进冰箱，再拿出来解冻很慢，且反复解冻肉就不新鲜了。肉放到冰箱冷冻层，记得分开保存，不要让连在一起了。吃的时候提前半小时拿出来自然解冻即可，着急的话就泡在冷水里，加速解冻（千万不要用热水，影响口感）。

猪肉怎么切

  刚刚从冰箱里拿出来的冻肉，解冻到似冻非冻的状态时切起来很听话，想怎么切就怎么切。但刚刚买回来的鲜肉切起来就比较麻烦了。

  我们切蔬菜的时候，由于蔬菜很脆，我们可以轻松的一刀到底，但肉都有一定韧性，所以需要一些细节。

  对于冻肉来说，解冻时间都是不固定的。标准就是：肉能轻松切动，又不过于软榻。切片时要注意看瘦肉的纹理，切片时要垂直于纹理来切，这样不塞牙，而且瘦肉还有很多细小的缝隙，垂直纹理切片后，在码味的时候淀粉和调料可以更好的进入到瘦肉的缝隙中，从而让肉更加细嫩。

  拿到一块肉不要直接来切，要看大小是否合适，不要搞的最后切出来的片巨大。我们需要先把大块的肉分成小份，分小份的时候是顺着纹理来切。改小时顺手把白色的筋膜去掉，这个吃不动。

  切片时左手半握拳，小指和拇指分别放在肉的两侧，其他手指搭在肉上面，中指的第一个关节抵着刀，其余任何手指不要超过中指关节。从刀的前半截下刀，切的时候刀往前推。

  切好的冻肉拿一个稍微宽松一点的碗或者盆用冷水冲洗几遍，直到肉完全变软。然后稍微攥干水分，不用太干，碗底看不到水就好了。然后开始码味。

  码味先撒一点盐、然后是白胡椒粉（一定是白胡椒，西餐才用黑胡椒），胡椒性状温热，不宜多放，只需要少许就能达到去腥增香的作用（半个指甲盖大小）。最后撒一些淀粉放在盆的角落，然后撒一勺料酒化开淀粉，然后用手抓伴肉。很多人做肉很柴就是没有做好抓伴这一步，不是三两下和匀就完事的，手指打开带点力气不停的抓肉，约抓伴一分钟。和不均匀的话再加少许水，最终抓到黏糊糊的感觉就行了。

  

  如果是鲜肉，因为鲜肉在摊位上摆了很久会有灰尘，需要先用温水清洗2遍（猪肉有油，冷水洗不干净，热水肉就熟了）。然后和冻肉一样，先观察肉的纹理，如果肉很大，还要先分成大小合适的小块、去掉筋膜。瘦肉切片一般就2mm厚。

  新鲜的肉切完后就不需要冲洗了，可以直接码味。操作方法一样：先撒盐，少许白胡椒粉，然后是淀粉、料酒，用力抓拌，太干的话再加点水。

  

  对于买到的不规则的瘦肉，就不能直接切成小块，需要先从筋膜连接的地方用刀分开。

  

  码味时使用了淀粉。无论是红薯淀粉、玉米淀粉、土豆淀粉、嫩肉粉都可以归类为淀粉。淀粉在加热工程中可以在原料的外表形成隔膜，组织原料水分流失，从而使菜肴更鲜嫩、饱满。市面上淀粉种类非常多，但除了价格不同，作用都大同小异，餐饮行业常用红薯淀粉和玉米淀粉。

  淀粉的用量很重要，用少了锁不住水分，淀粉太多了就浑汤了，使炒的菜肴过于黏稠。这个需要长久的经验。

  

肉菜入门---肉片汤

码肉+烧汤 -> 水开放菜+调料 -> 出锅

蔬菜肉片汤

常见的绿叶菜有：空心菜、木耳菜、小白菜、菠菜、豆尖、生菜、油麦菜、茼蒿、冬葵、苦菊。跟随季节使用不同的原料。接下来以菠菜为例子。

买到的菠菜，把根单独摘下来（不要扔掉，这个很好吃），叶子和根茎直接掐成段。然后洗菜。根部有很多泥土，需要单独关照。如果根部很粗，需要切成两半，方便做熟。

生姜切2到3片，放进汤中增香提味。再切点葱花备用。

  1. 锅中倒水，放入切好的姜片，开始烧水；
  2. 水烧开后先放一勺盐，让汤有个底味，这样煮肉时水就不会把我们之前码肉时的盐吸走；
  3. 把肉抓散，防止煮出来的肉一坨一坨的，然后就可以在水中放肉了，记得把肉打散放进去。放肉时火一定要调小，等下完肉再开大火；
  4. 肉放完后不要着急，等个10秒钟再搅拌均匀，让肉片均匀受热；成团的肉还需要打散；
  5. 水再次烧开，看不到红色的生肉时，就可以下菠菜了；码肉的淀粉融入了汤里，所以水烧开会有泡泡，此时把火调小就可以消除泡泡；
  6. 等汤再次烧开，就可以放盐、鸡精、味精。由于之前已经放过盐了，所以先放鸡精和味精，用量比炒蔬菜少很多，不要放多了；搅开后尝一下，咸度不够再放盐；够了就可以准备出锅了；放调料时火调小；
  7. 出锅前倒入一点点油，保证风味且营养均衡，用啥油都可以，但不建议菜籽油，这个味道太重了，不适合清汤类菜品；
  8. 出锅后撒上葱花；

做这个菜需要注意，肉片不宜煮太久，2分钟左右就可以出锅了，否则就会柴。

平菇肉片汤

可以用平菇、香菇、海鲜菇、茶树菇、蟹味菇来做。本文以平菇为例子。

平菇选择大小适中、杆子小叶子大、颜色微微发墨绿色的为上品。颜色墨绿说明成熟度刚好。平菇叶子太大说明成熟过度。平菇的杆子绵软，杆子越小越好。

买回来的平菇，如果超市没有去掉平菇的根，需要先切掉。所有蘑菇都需要这个步骤。

去掉根的平菇分成小朵，再把小朵的平菇撕小一点，然后清洗。清洗时要注意温柔一点，不然就碎了。平菇不是从土里种出来的，所以没有泥。轻轻淘洗两遍，洗去灰尘就好。

步骤和蔬菜肉片汤基本一样，先码肉，然后：

  1. 锅中倒水，放入切好的姜片，开始烧水；
  2. 蘑菇不容易熟，所以先放蘑菇
  3. 蘑菇不容易熟，煮2分钟后放盐，让汤有个底味，然后放肉。盐一定要比肉先下锅；
  4. 肉片再煮2分钟，如果有浮沫是血水，需要撇出来，否则影响口感；
  5. 肉快熟时放味精鸡精，尝一下味道，不够再放盐；放调料时火调小；
  6. 淋一点油，出锅，放葱花；

丝瓜肉片汤

市面上有两种丝瓜：普通的和细长的，买哪种都可以。长相奇葩不方便处理的不买，有坑洼的不买，有局部变色的不买。

买回来用刨子去皮，去头去尾。清水冲洗一遍。先切成食指长的段，然后每段再滚着切成粗细均匀的丝瓜条（先切成2半再切）。切好后放一边备用。码号的肉放一边备用。

  1. 锅中倒水，放入切好的姜片，开始烧水；
  2. 水开后放丝瓜；
  3. 2分钟左右快熟后放入盐，然后放入肉片；
  4. 2分钟左右放调料，淋入食用油，出锅后撒葱花；放调料时火调小；

薄片黄瓜肉片汤

买回的黄瓜仔细清洗后去头去尾，然后斜着切。如果正着切只能切出圆片，斜着切就可以切出大大的薄片。这个片切的越薄越好。

如果刀工实在是太差了，切不出薄片，那么就用刨子来一层层切也可以。

码肉后开始做汤：

  1. 锅中倒水，放入切好的姜片，开始烧水；
  2. 水开后放盐，然后放入肉片；
  3. 2分钟左右，没有红色生肉了，放入黄瓜片，黄瓜片要打散，防止夹生；
  4. 2分钟左右放调料，淋入食用油，出锅后撒葱花；放调料时火调小；

番茄肉片汤

番茄选择颜色通红，稍微用力捏的时候手感偏软的番茄。颜色不统一且捏着发硬的番茄是催熟番茄，口感欠佳。

挑选2个大小适中的番茄放入锅中，用开水翻来覆去烫一分钟。然后拿到水龙头下边冲洗边去皮。从中间切成2半，番茄头部中间的硬芯吃不动，要切掉。然后把番茄像切西瓜一样切成小块。

这个菜除了姜，还需要大蒜。大蒜的味道和番茄很搭配。用2瓣蒜切片备用。码肉后开始做。

  1. 锅烧干，放入少许植物油。如果家里有猪油更好，一起放；
  2. 放入姜片、蒜片，炒香后，番茄下锅炒一下；
  3. 当番茄炒出酱汁，能明显闻出香味后（3分钟左右），加水
  4. 汤烧开后放盐，然后加肉片；
  5. 2分钟快熟了，就放鸡精味精，盐度不够再放盐
  6. 炒番茄时已经放过油了，这里不再放油，直接出锅。撒上葱花。

酸菜肉片汤

超市直接买成品鱼酸菜，再买袋装野山椒就可以。

酸菜取出来挤干水分，切成小块。菜帮子部分用斜刀切成薄片，叶子展开切成小块。如果酸菜自带姜和辣椒，可以拿来直接用。需要注意姜不一定品质很好，可能含有很厚的木质层，需要把肉质层剥出来。

超市买的酸菜一般都很咸，需要把切好的酸菜放到盆里清洗2遍，把多余的盐分洗掉。攥干水分备用。

野山椒很辣，用2、3根就可以了，切成小段和酸菜放一起。多余的冻起来就行。泡椒水是很好的东西，不要扔掉，放一边备用。

然后再切一点姜片。也可以再来一点金针菇，酸菜汤搭配蘑菇很不错。把金针菇根部切掉，撕成小束，清洗干净备用。清洗很简单，简单冲一下就行。

  1. 锅烧干，放入油，有猪油更好一起放；
  2. 放几粒花椒、生姜爆香；
  3. 放入酸菜、野山椒，翻炒一分钟后加水，然后再倒入一勺野山椒水；
  4. 汤烧开后转小火，再慢煮2、3分钟，把酸菜的香味熬煮出来；
  5. 转大火，放入金针菇，盖上盖子焖煮一分钟；
  6. 酸菜、野山椒、野山椒水都有盐，所以不需要再额外加盐，直接放肉片；
  7. 放入一汤匙的白醋，仅仅依靠酸菜的酸度是不够的；再加入一点耗油；
  8. 放入味精、鸡精，这个汤的口味重，所以可以稍微给多一点。
  9. 炒酸菜时放过油了，不再加油，出锅前尝尝味道，盐度不够放盐、酸度不够加白醋；

酸汤类菜肴，用的是白醋，可千万不要用成陈醋了，味道不一样。

Q：是先放菜还是先放肉？

A：煮肉的时间就是2分钟，2分钟煮不熟的蔬菜，就先放蔬菜；很快成熟的蔬菜（各种绿叶菜），就先放肉。

 

炒肉公式

本节会学习三种风味的家常菜炒肉风味：豆瓣酱炒出的豆瓣风味、青椒炒出的青椒香、干辣椒炒出的胡辣香。

本节炒肉菜都需要提前腌制肉，这个步骤就不再复述了。

黄瓜炒肉

  提前腌肉；准备几瓣大蒜，切成片；掰掉一块生姜，清洗干净，先切3到4片姜片，然后切姜丝。姜切成丝后更出味。把切好的姜蒜和腌的肉放在一起。然后再取一勺豆瓣酱，也和肉放在一个容器备用。

  在家里炒菜，最好是把葱姜蒜、豆瓣酱和肉都放在一起，一起下锅炒。在饭店里，正常的步骤是先把豆瓣酱炒香，然后放入姜蒜，爆香后再放入准备好的肉片，全程旺火，一道菜1、2分钟就好了。但家里天然气火力太小了，按照饭店里的做法的话，锅里就始终保持一个低油温状态，炒菜会变慢，这样炒出来的肉又老又柴。一起放进去的话，可以让刚刚烧热的油直接给到肉，模拟饭店的旺火。

  炒菜选土黄瓜最好，最好选直溜的，更好切。实在买不到用普通黄瓜也可以。黄瓜清洗后去头去尾，然后竖着切成2半，每一半再单独切片，切片时刀可以斜一点，切出来的片更大。炒肉需要黄瓜在很短时间内成熟，所以黄瓜片切的要薄，1mm厚。用这个方法切两根黄瓜。

炒肉菜全程大火，并且放油不能小气，不然要么油烟味太大，要么颜色黑黢黢的。

  1. 锅烧干，倒油烧热，等油冒烟；
  2. 油冒烟后，放入几粒干花椒，不要等，直接把肉、葱姜蒜、豆瓣酱一起下锅，用锅铲滑散均匀受热。此时油温很高，可能会四处飞溅油滴，一定要迅速把肉滑散，把温度降下来；不断翻炒；
  3. 看不到红色的生肉，就代表有6、7成熟了，放入黄瓜。不要放早了，否则黄瓜拉低了锅中的温度，拉长了炒肉时间，会让肉变柴。
  4. 黄瓜开始打蔫的时候代表快熟了，可以放调料，此时用小火，放一勺生抽、味精、鸡精、一小点陈醋；这个不需要放盐了，码肉的时候放盐了，生抽、豆瓣酱也有盐；
  5. 开大火，和匀调料。出锅。

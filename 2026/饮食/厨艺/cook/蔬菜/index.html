三、常见蔬菜

本文字数： 2.7k

凉拌菜

拍黄瓜

主料：黄瓜两根；

调料：生姜、大蒜、盐、味精、鸡精、生抽、陈醋、花椒油、芝麻油

  1. 黄瓜洗净，不用去皮。把尾部的蒂去掉，头的部分先留着；
  2. 左手握住头部，右手持刀往下拍，使劲拍，拍碎一点容易入味（也不要太碎，不然就失去口感了），彻底拍碎后去掉头部。
  3. 刀斜着45°切成小块，间距2cm左右，放入盆中；
  4. 要2瓣大蒜，一点生姜，混合切成沫，放入盆中；
  5. 放入调料：一勺盐，半勺味精、半勺鸡精、2勺生抽、1勺陈醋、半勺花椒油、半勺芝麻油
  6. 搅拌均匀

凉拌金针菇

主料：金针菇一把

调料：盐、味精、白糖（白砂糖即可）、生抽、陈醋、花椒油、芝麻油、生姜、大蒜、红小米椒、辣椒油

金针菇根部比较老，要切掉一部分。撕成小束。淘洗两遍，金针菇没有什么泥沙，稍微清洗即可。

  1. 锅中烧水，水开后下入金针菇，大概煮3分钟基本熟透，倒出来后过凉水，滤干水份备用；
  2. 用小碗准备调料汁：一勺盐、一勺味精、一勺白糖、三勺生抽、两勺陈醋、几滴芝麻油、几滴花椒油、两勺辣椒油、一点姜蒜末、2到3个小米椒的辣椒碎；
  3. 金针菇装盘，把料汁淋在金针菇上。
  4. 加一点葱花点缀；

凉拌豇豆

主料：豇豆一把

调料：盐、味精、白糖、生抽、陈醋、花椒油、芝麻油、生姜、大蒜、红小米椒、辣椒油

豇豆有两种：绿色的和紫色的。绿色的豇豆口感爽脆，紫色豇豆口感偏面。豇豆细一点的、捏起来硬邦邦的就比较嫩，很大根的，捏起来往下塌的就比较老。

豇豆择菜和四季豆类似。找到尖的那头，逆着把头撕下来，然后从刚刚撕完筋的一侧掐断让另一侧的筋露出来；把另一侧的筋掐掉，再掐断，循环往复。择菜时注意黑点，这个是虫眼，这一节掐掉不要。

豇豆本身没有什么筋，如果豇豆本身品质不错，可以直接用刀切成5cm左右的段。

择好的豇豆淘洗2遍，滤干水份备用。

经典家常菜

炝炒莲花白

食材：圆白菜、2g花椒、7g干辣椒、22g生抽、20g米醋、2g盐、1g味精、5g糖

莲花白是四川的一种菜，在家做的时候，就买那种松弛的圆白菜就行。买回来的圆白菜从中间切2半，把中间的杆去掉不要。这道菜很注重火候，杆和叶成熟时间不一样，所以只要叶子。把叶子用手撕成小片。圆白菜一定不要超过家里锅的高度，家中火不够大，菜太多温度下降的特别快，出菜影响口感。

还是因为火候很重要，所以要把碗汁兑好。生抽、米醋、糖、味精、盐按照前面的克重来加。

  1. 锅中倒油，烧热后放入花椒，关小火炸香；
  2. 倒入一小点凉油，把干辣椒倒进锅中炸香；
  3. 辣椒变棕红色后，把圆白菜放进锅中，全程开大火翻炒；
  4. 菜变颜色就可以沿着锅边倒入碗汁，翻炒一下出锅；

 

家常豆腐

这道菜先把豆腐煎出金黄的表皮，然后再重新烹调调味。

主料：豆腐一块。一般用嫩豆腐，表面煎出酥皮了内部还是嫩的，但下锅煎的时候新手很可能把豆腐弄碎，所以新手可以用老豆腐

辅料：猪瘦肉或者牛瘦肉一小块

调料：盐、豆瓣酱、生抽、料酒、胡椒粉、味精、鸡精、淀粉、生姜、大蒜、蒜苗、油

备料：

  1. 取一块豆腐，先切2半，然后再切1cm厚的片；放一边备用；
  2. 把肉洗净后切小块，然后剁成肉沫，放一边备用；
  3. 2瓣大蒜、一小块生姜，都切成颗粒；
  4. 两颗蒜苗，根洗净后切成段：根部斜刀切，叶子直接切，放一边备用；
  5. 一勺淀粉、一勺水，搅拌均匀做成水淀粉

把豆腐煎一下，剪到两面金黄，煎过的豆腐表皮失去水分孔隙变大，更好吸收调料:

  1. 锅烧干后，二档火，放薄薄的一层油，再均匀的撒一些盐，既可以防止豆腐粘锅，也可以让豆腐提前入味；晃一晃锅底，让锅底均匀铺满油；
  2. 依旧二档小火，用筷子轻轻夹起豆腐，均匀铺在锅底，拜访紧凑一下。如果一次煎不完可以多次来；全程二档火，慢慢煎。煎的时候时不时晃动锅底，防止粘锅；没隔一分钟都可以晃一下；
  3. 如果豆腐边角变黄，就可以翻面了；
  4. 第二面也变黄了，再翻个面复煎一下；2分钟左右再翻个面；然后出锅；

最后可以重新烹饪调味：

  1. 2档小火，锅不用洗，补一点油，然后放入一勺豆瓣酱，慢慢翻炒；豆瓣酱炒香后，放入姜、蒜；
  2. 姜蒜翻炒10秒，就放入肉沫，用锅铲尽快把肉沫散开，不停翻炒；
  3. 肉沫炒散后，放入一点胡椒粉，一小勺料酒，继续翻炒片刻，把肉沫水分炒干；
  4. 把豆腐放进来，加水没到豆腐8分满（别加太多，这个不是豆腐汤），然后开大火，把豆腐弄匀后加入2勺生抽，弄均匀后，盖上锅盖，继续用2档小火炖煮；
  5. 水开后再煮2分钟，打开盖子开始调味。先尝一下锅里的汤，如果盐度合适就不用加盐，否则要补一点盐，加一点鸡精、味精，调料和匀，动作轻一点别把豆腐弄碎了；
  6. 切好的蒜苗倒入锅中，翻炒；
  7. 把水淀粉搅散，倒入锅中勾芡，可以让汤汁变得浓稠，不停搅拌20秒后出锅；

 

麻婆豆腐

主料：豆腐一块，老豆腐嫩豆腐都可以，老豆腐吃起来更香、嫩豆腐口感嫩滑

辅料：猪/牛瘦肉一小块

调料：豆瓣酱、豆豉、盐、生抽、味精、鸡精、辣椒粉、蒜苗2颗、淀粉、花椒粉、食用油

要把豆腐切成拇指大小的方块，切小一点方便入味。先横着慢慢切，正常大小的豆腐切两刀，变成三个厚片就行，每层1.2厘米厚。接着码放整齐，竖着切，切成大小统一的小方块。切好都放一边备用。

一小块瘦肉，洗净后切成肉沫。放一边备用。

两颗蒜苗，洗净后去掉根部。茎的部分用刀拍破，然后和叶子一起切成1cm长的小段。放一边备用。

拿出几颗豆豉，稍微改小，放一边备用。

取2大勺淀粉，加小半碗水，和匀做成水淀粉。

  1. 锅中加冷水，水要多一点，把豆腐倒进来，开大火焯水。焯水的目的是去除豆腐的豆腥味。需要加入2勺食盐，让豆腐有底味。大火把水烧开后，再转中小火煮一分钟；煮完后把豆腐倒出来沥干水分备用；
  2. 锅烧干、倒油，中小火，倒入一大勺豆瓣酱；豆瓣酱炒香后倒入豆豉、2大勺辣椒粉，火一定不要大，不然辣椒就炒糊了；
  3. 辣椒炒10来秒，出香味后倒入肉沫翻炒，炒散后撒一小勺胡椒粉、一小勺料酒，然后再炒30秒左右；
  4. 倒入清水，能刚好末过豆腐，转大火把水烧开；
  5. 水开后转中小火调味：4勺生抽，和匀时尝尝咸度，此时汤的咸度要和日常吃菜的咸度一样，不够就补盐，汤要咸一点，否则一会煮豆腐没味；
  6. 把豆腐倒入锅中，锅铲推散推均匀，用二档小火慢慢煮，让豆腐吸收味道。煮的时候用锅铲时不时铲一下锅底，免得粘锅；
  7. 看时间，大概4~5分钟，锅里的水还剩一半时，放入一勺鸡精、一勺味精，和匀。需要注意，由于锅里全是豆腐，所以大概豆腐露出1/3的时候，汤就是还剩一半的量；千万不要等豆腐露出一半了再放调料，此时汤就很少了；
  8. 把水淀粉抓散，倒入1/3，用锅铲背部不停的轻轻地推，和匀；等半分钟左右淀粉熟了，再倒剩下的1/3，再不停的推半分钟；
  9. 倒入切好的蒜苗，再把剩下的水淀粉全部倒进了，不停的推半分钟。淀粉分三次加的原因是加入的淀粉会让锅里的汤汁一次比一次浓稠，淀粉可以更好的包裹食材。
  10. 出锅，表面轻轻撒一层花椒粉；

AI初期的这几年

AI核心概念串讲

一、底层引擎：LLM（Large Language Model）

  LLM全称“Large Language Model”，中文翻译为“大语言模型”，简称“大模型”。基本上现在所有的大模型都是基于Transformer这个架构训练出来的，这个架构最早是由Google团队在2017年提出，对应论文名是“Attention Is All You Need”。虽然Google提出了这个概念，但真正把这个概念引爆的是OpenAI，2022年底GPT-3.5横空出世，是第一个真正达到可用级别的大模型。2023年3月份GPT-4发布，把AI能力的天花板拉到了新的高度。之后随着Claude、Gemini等大模型涌现，现在市场上有多个模型在竞争。

  AI的工作方式本质上就是一个文字接龙游戏。举个例子，我对AI提问“这个文档写的怎么样”，大模型收到这句话后，会在内部进行一系列运算，然后预测下一个出现概率最高的词，比如“特别”，然后吐出这个词；但模型不会停下来，而是把刚刚吐出的“特别”这个词抓回来，和刚刚的输入“这个文档写的怎么样”拼接起来，成为一个新的输入，然后大模型继续预测下一个出现概率最高的词，比如“得”；大模型重复操作，把“得”再次拼接起来成为新的输入后预测下一个词，比如“好”；如果大模型发现这句话已经说完了，那么大模型会再吐出一个结束标识符，这个回答就彻底结束了。

  这就是大模型底层的生成原理，我们看到大模型的输出，就是一个词一个词的输出。

二、数据处理单元：Token

  上文中说的大模型每次回答吐出一个词是个方便理解的简化说法，现实情况是：大模型本质上是个庞大的数学函数，里面跑的全是矩阵运算，接收的是数字，输出的也是数字，并不认识人类的文字。所以就像各种编程语言一样，人类和大模型之间也必须有一个翻译官，这个翻译官就叫Tokenizer，他负责的是编码和解码两件事，编码就是把文字变成数字，解码就是把数字变成文字。

  还是用之前的例子，我们给AI输出“这个文档写的怎么样”，AI输出“特别得好”，实际发生的流程如下：

  1. Tokenizer对输入的文字进行编码，把文字变数字，这个步骤分两步：
    1. 切分：把输入切成一个一个的片段，如“这个”、“文档”、“写的”、“怎么样”，这些片段就叫做Token；
    2. 映射：大模型只认识数字，Tokenizer会把每一个Token对应到一个数字上；这个数字就叫做Token ID,Token ID和Token是一一对应的，本质上是一个意思，只不过表达方式不一样，一个是文字，一个是数字;
  2. Tokenizer把生成的Token ID组成列表，送入大模型；
  3. 模型经过运算，吐出一个Token ID;
  4. 解码：Tokenizer把这个Token ID翻译回Token。解码环节不会进行切分，因为大模型一次只吐出一个Token;
  5. 如果话还没说完，大模型持续吐出Token，然后Tokenizer进行解码，直到终止符。

  所以Token就是大模型处理文本的最基本单位。

  上述的例子也只是方便理解，实际上Token和词并不是一一对应的关系，OpenAI提供了一个把文本转化为Token的页面，我们可以在这里看看一句话是怎么拆分成Token的：

语言单位 于Token的关系 示例
中文词语 非一一对应关系，可能被拆分 程序员->"程序"、“员”
简单英文单词 常见简单单词会对应一个Token hello
复杂英文单词 可能被拆分 helpful->"help"、"ful"
特殊字符 一个字符可能被多个Token表示

  所以我们不能把词和Token理解为纯粹的一对一关系，可以把Token理解为大模型自己的一套文本切分规则，切出的每一块就是大模型能处理的一个最小单位。平均来讲，一个Token对应0.75个英文单词或1.5~2个中文汉字，量化的看，40万Token就对应60万至80万的汉字或30万英文单词。

三、临时记忆体：Context

  大模型本质上就是数学函数，给祂一个输入就给我们一个输出，并不像人一样有记忆。所以我们每次给大模型发消息的时候，并不只发送我们的问题，背后的程序会把之前对话的整段历史找出来一起发出去，这样大模型每次看到的就是完整的对话内容了。

  这就引出了context这个概念，中文叫“上下文”。Context代表大模型每次处理任务时所接收到的信息总和。Context的内容除包括：对话历史、用户问题、当前输出的Token、工具列表、System Prompt等内容。

  那么一个Context到底能装多大，这就引出了Context Window的概念，中文叫“上下文窗口”，代表Context能容纳的最大Token数量。Context Window为1万，就代表模型最多能处理1万个Token，目前主流的大模型的Context Window大小都在100万以上，大概有150万汉字，整个哈利波特全集都可以装下。

  虽然当前主流的大模型Context Window都很大，但我们也不可能把全部东西都丢给大模型。设想一个场景：假如我们有一个上千页的产品手册，希望大模型根据这个产品手册来回答用户的各种问题。如果我们把这个产品手册和用户问题一起丢给大模型，显然不是合理的方法，产品手册太长了，即使Context Window足够大，我们的成本也无法控制。所以就需要一个叫RAG的技术了，中文叫“检索增强生成”，它可以从产品手册中抽取用户问题最为匹配的几个片段，然后只把这几个片段丢给大模型，让大模型只根据这几个片段回答问题。有了这个技术，就不受大模型的Context Window的大小限制了，成本也会低很多。

四、指令交互：Prompt

  Prompt，中文叫提示词，是大模型接收的具体问题或指令。比如向大模型提需求“帮我翻译这句话”，这就是一个Prompt。

  Prompt怎么写直接决定了大模型的输出质量。假如你只给大模型说“帮我翻译这句话”，那么大模型可能翻译为英文、法文或各种奇妙语言。一个好的Prompt应该是清晰的、明确的。有个专门的领域叫Prompt Engineering，中文翻译“提示词工程”，专门研究怎么把话说清楚，让大模型更精准的理解意图。但这个领域已经没啥人再提了，因为这个领域本质就是把话说清楚，门槛太低，且大模型能力越来越强，即使指令含混不清，大模型也能大概猜出意思。

 

  有些时候我们不仅要给大模型具体的任务，也要告诉大模型人设和具体做事规则，这就引出了两种Prompt：

  • User Prompt：用户提示词，用于说明具体的任务，是用户自己输入的；
  • System Prompt：系统提示词，用于说明人设和规则，是开发者在后台配置的；

  举个例子：有一个数学辅导机器人，我们希望他不要直接告诉学生答案，要引导学生思考。System Prompt就可以这样设置：“你是一个耐心的数学老师，当学生问你问题的时候不要直接给出答案，而是一步一步引导学生思考，帮助他们理解思路”。这个是开发者在后台设置的，用户看不到，但它会一直影响大模型的行为。这样当用户在对话框输入User Prompt "3+5等于几"的时候，大模型就不会直接回答“8”，而是教学生怎么计算。

五、外部能力扩展：Tool

  大模型本质上就是个文字接龙游戏，它的能力是根据训练数据来预测下一个词。但如果我们问大模型“今天北京天气如何”，大模型根部就无法获取当日天气内容，这就需要Tool来解决了。

  Tool本质上就是函数，我们给它输入，它就返回一个输出。比如说天气查询的Tool，我们给它城市和日期的输入，它内部一通操作，返回给我们天气数据。Tool通过提供各种外部能力，让大模型能够感知和影响外部环境。

辣椒怎么买

  • 又大又圆，颜色丰富多彩的辣椒叫甜椒，也叫彩椒，辣度很低，甚至发甜；颜色鲜艳适合做配菜，也可以做一些特殊的菜肴
  • 个头适中的青椒是家中经常使用的，辣度偏低，香味很足，适合当配菜，让菜品有青椒香气，也可以单独做菜，做成虎皮青椒；很多人不喜欢吃青椒籽，有一个很方便的去籽方法：左手握住青椒，右手拇指从根部往下按，然后就可以连根带籽拔出来了；
  • 又长又粗的叫螺丝椒，整体辣度适中，比青椒辣，和青椒的用途很接近；
  • 比逻辑椒更细一点的叫 二荆条，这个就更辣一点，属于中等偏上，日常除了配菜外，也可以适当切一两个给菜品增加一点鲜辣的味觉体验；
  • 二荆条很长，比二荆条短一点的叫 美人椒，美人椒和二荆条辣度相近，用法相同；
  • 红色或绿色的又小又细的就是让人闻风丧胆的小米椒，辣度很高。青小米椒清香味更浓，辣度比红小米椒稍低，一般会搭配使用；
  • 和小米辣长得差不多的黄色的，就是野山椒，这个比小米辣还要更辣，除了辣没有其他特点

总结：一般来讲，个头越长、越粗、越大、肉质越厚的辣椒辣度越低；个头越短、越细小、肉质越薄的辣椒辣度更高。相同品种青绿色的辣度更低，深绿色的辣度更高（成熟度越高颜色越深）；相同品种打蔫起皱的辣度更低、坚挺饱满色泽光亮的辣度越高（生长时间短的辣椒果皮松弛容易失去水分）。

猪肉怎么买

  买肉不需要记住什么前腿肉、后腿肉、二刀肉、梅花肉，只需要记住我们是要瘦肉还是肥肉就行。纯瘦肉的价格很贵，瘦肉多肥肉少的肉性价比很高。

  如果炒肉总是很柴，可以试试有明显脂肪纹理的肉，这种肉炒出来更鲜嫩，对新手很友好。这种肉就是夹子肉/二刀肉。优点是价格便宜、性价比高；同时可以买到瘦肉和肥肉，一肉两用；带脂肪纹理的肉不容易柴。这种肉挑选时看瘦肉占比越多越好。但这种肉的缺点是需要和肥肉一起买，不喜欢吃肥肉的话会浪费；肉形不规整，切出来的肉丝炒的时候很容易碎，不适合用来切肉丝。

  不在意价格想吃纯瘦肉的话，可以买散切的瘦肉，挑选方法也一样：有脂肪纹理的适合炒肉片；如果想切肉丝，就挑选一块四四方方的净瘦肉，比较好操作。

  炒菜不建议用里脊肉，虽然里脊肉四四方方的看起来很漂亮，但处理不好很容易柴。但里脊肉很规整，很适合切肉丝。里脊肉还分大里脊和小里脊，看粗细就行，小里脊肉质细嫩，怎么做都好吃。

  五花肉是很常用的肉，这种肉有很明显的肥瘦纹理，是做回锅肉、红烧肉、梅菜扣肉、粉蒸肉最理想的食材。买五花肉的时候也是尽量挑瘦肉多且纹理清晰的部分。

   排骨尽量买一条一条的中排，散装砍好的价格会便宜一点，但骨头大肉少，口感相对差一点，尽量挑选骨头小肉多的。

  猪腿肉一般会买猪后腿，因为肉比较多，瘦肉占比高。猪前腿去掉骨头后，肉就很少了，根本不够吃。猪腿的骨头非常硬，买的时候让摊贩砍好了再带回家。

  

  肉买回家后，不要直接放冰箱，先清洗，分成小份。有些地方的摊贩在卖肉的时候会烧猪皮，这样可以去除残留的猪毛。如果购买的时候没有这个服务，猪皮上还残留有猪毛，可以把锅烧烫，然后把猪肉放进去滋啦几下，把肉皮烫的金黄起皱，上面的毛就没了；再用热水清洗猪肉，然后用刀刮猪毛（或者拿钢丝球刷，不过要注意钢丝球容易断）。清洗完成后分块。先把瘦肉从上面剔下来，纯瘦的部分可以用来炒或者煮汤，肥瘦的部分可以用来做回锅肉，也可以直接切成片炒着吃。之所以要切成小块是因为方便解冻，如果一大块肉放进冰箱，再拿出来解冻很慢，且反复解冻肉就不新鲜了。肉放到冰箱冷冻层，记得分开保存，不要让连在一起了。吃的时候提前半小时拿出来自然解冻即可，着急的话就泡在冷水里，加速解冻（千万不要用热水，影响口感）。

猪肉怎么切

  刚刚从冰箱里拿出来的冻肉，解冻到似冻非冻的状态时切起来很听话，想怎么切就怎么切。但刚刚买回来的鲜肉切起来就比较麻烦了。

  我们切蔬菜的时候，由于蔬菜很脆，我们可以轻松的一刀到底，但肉都有一定韧性，所以需要一些细节。

  对于冻肉来说，解冻时间都是不固定的。标准就是：肉能轻松切动，又不过于软榻。切片时要注意看瘦肉的纹理，切片时要垂直于纹理来切，这样不塞牙，而且瘦肉还有很多细小的缝隙，垂直纹理切片后，在码味的时候淀粉和调料可以更好的进入到瘦肉的缝隙中，从而让肉更加细嫩。

  拿到一块肉不要直接来切，要看大小是否合适，不要搞的最后切出来的片巨大。我们需要先把大块的肉分成小份，分小份的时候是顺着纹理来切。改小时顺手把白色的筋膜去掉，这个吃不动。

  切片时左手半握拳，小指和拇指分别放在肉的两侧，其他手指搭在肉上面，中指的第一个关节抵着刀，其余任何手指不要超过中指关节。从刀的前半截下刀，切的时候刀往前推。

  切好的冻肉拿一个稍微宽松一点的碗或者盆用冷水冲洗几遍，直到肉完全变软。然后稍微攥干水分，不用太干，碗底看不到水就好了。然后开始码味。

  码味先撒一点盐、然后是白胡椒粉（一定是白胡椒，西餐才用黑胡椒），胡椒性状温热，不宜多放，只需要少许就能达到去腥增香的作用（半个指甲盖大小）。最后撒一些淀粉放在盆的角落，然后撒一勺料酒化开淀粉，然后用手抓伴肉。很多人做肉很柴就是没有做好抓伴这一步，不是三两下和匀就完事的，手指打开带点力气不停的抓肉，约抓伴一分钟。和不均匀的话再加少许水，最终抓到黏糊糊的感觉就行了。

  

  如果是鲜肉，因为鲜肉在摊位上摆了很久会有灰尘，需要先用温水清洗2遍（猪肉有油，冷水洗不干净，热水肉就熟了）。然后和冻肉一样，先观察肉的纹理，如果肉很大，还要先分成大小合适的小块、去掉筋膜。瘦肉切片一般就2mm厚。

  新鲜的肉切完后就不需要冲洗了，可以直接码味。操作方法一样：先撒盐，少许白胡椒粉，然后是淀粉、料酒，用力抓拌，太干的话再加点水。

  

  对于买到的不规则的瘦肉，就不能直接切成小块，需要先从筋膜连接的地方用刀分开。

  

  码味时使用了淀粉。无论是红薯淀粉、玉米淀粉、土豆淀粉、嫩肉粉都可以归类为淀粉。淀粉在加热工程中可以在原料的外表形成隔膜，组织原料水分流失，从而使菜肴更鲜嫩、饱满。市面上淀粉种类非常多，但除了价格不同，作用都大同小异，餐饮行业常用红薯淀粉和玉米淀粉。

  淀粉的用量很重要，用少了锁不住水分，淀粉太多了就浑汤了，使炒的菜肴过于黏稠。这个需要长久的经验。

  

肉菜入门---肉片汤

码肉+烧汤 -> 水开放菜+调料 -> 出锅

蔬菜肉片汤

常见的绿叶菜有：空心菜、木耳菜、小白菜、菠菜、豆尖、生菜、油麦菜、茼蒿、冬葵、苦菊。跟随季节使用不同的原料。接下来以菠菜为例子。

买到的菠菜，把根单独摘下来（不要扔掉，这个很好吃），叶子和根茎直接掐成段。然后洗菜。根部有很多泥土，需要单独关照。如果根部很粗，需要切成两半，方便做熟。

生姜切2到3片，放进汤中增香提味。再切点葱花备用。

  1. 锅中倒水，放入切好的姜片，开始烧水；
  2. 水烧开后先放一勺盐，让汤有个底味，这样煮肉时水就不会把我们之前码肉时的盐吸走；
  3. 把肉抓散，防止煮出来的肉一坨一坨的，然后就可以在水中放肉了，记得把肉打散放进去。放肉时火一定要调小，等下完肉再开大火；
  4. 肉放完后不要着急，等个10秒钟再搅拌均匀，让肉片均匀受热；成团的肉还需要打散；
  5. 水再次烧开，看不到红色的生肉时，就可以下菠菜了；码肉的淀粉融入了汤里，所以水烧开会有泡泡，此时把火调小就可以消除泡泡；
  6. 等汤再次烧开，就可以放盐、鸡精、味精。由于之前已经放过盐了，所以先放鸡精和味精，用量比炒蔬菜少很多，不要放多了；搅开后尝一下，咸度不够再放盐；够了就可以准备出锅了；放调料时火调小；
  7. 出锅前倒入一点点油，保证风味且营养均衡，用啥油都可以，但不建议菜籽油，这个味道太重了，不适合清汤类菜品；
  8. 出锅后撒上葱花；

做这个菜需要注意，肉片不宜煮太久，2分钟左右就可以出锅了，否则就会柴。

平菇肉片汤

可以用平菇、香菇、海鲜菇、茶树菇、蟹味菇来做。本文以平菇为例子。

平菇选择大小适中、杆子小叶子大、颜色微微发墨绿色的为上品。颜色墨绿说明成熟度刚好。平菇叶子太大说明成熟过度。平菇的杆子绵软，杆子越小越好。

买回来的平菇，如果超市没有去掉平菇的根，需要先切掉。所有蘑菇都需要这个步骤。

去掉根的平菇分成小朵，再把小朵的平菇撕小一点，然后清洗。清洗时要注意温柔一点，不然就碎了。平菇不是从土里种出来的，所以没有泥。轻轻淘洗两遍，洗去灰尘就好。

步骤和蔬菜肉片汤基本一样，先码肉，然后：

  1. 锅中倒水，放入切好的姜片，开始烧水；
  2. 蘑菇不容易熟，所以先放蘑菇
  3. 蘑菇不容易熟，煮2分钟后放盐，让汤有个底味，然后放肉。盐一定要比肉先下锅；
  4. 肉片再煮2分钟，如果有浮沫是血水，需要撇出来，否则影响口感；
  5. 肉快熟时放味精鸡精，尝一下味道，不够再放盐；放调料时火调小；
  6. 淋一点油，出锅，放葱花；

丝瓜肉片汤

市面上有两种丝瓜：普通的和细长的，买哪种都可以。长相奇葩不方便处理的不买，有坑洼的不买，有局部变色的不买。

买回来用刨子去皮，去头去尾。清水冲洗一遍。先切成食指长的段，然后每段再滚着切成粗细均匀的丝瓜条（先切成2半再切）。切好后放一边备用。码号的肉放一边备用。

  1. 锅中倒水，放入切好的姜片，开始烧水；
  2. 水开后放丝瓜；
  3. 2分钟左右快熟后放入盐，然后放入肉片；
  4. 2分钟左右放调料，淋入食用油，出锅后撒葱花；放调料时火调小；

薄片黄瓜肉片汤

买回的黄瓜仔细清洗后去头去尾，然后斜着切。如果正着切只能切出圆片，斜着切就可以切出大大的薄片。这个片切的越薄越好。

如果刀工实在是太差了，切不出薄片，那么就用刨子来一层层切也可以。

码肉后开始做汤：

  1. 锅中倒水，放入切好的姜片，开始烧水；
  2. 水开后放盐，然后放入肉片；
  3. 2分钟左右，没有红色生肉了，放入黄瓜片，黄瓜片要打散，防止夹生；
  4. 2分钟左右放调料，淋入食用油，出锅后撒葱花；放调料时火调小；

番茄肉片汤

番茄选择颜色通红，稍微用力捏的时候手感偏软的番茄。颜色不统一且捏着发硬的番茄是催熟番茄，口感欠佳。

挑选2个大小适中的番茄放入锅中，用开水翻来覆去烫一分钟。然后拿到水龙头下边冲洗边去皮。从中间切成2半，番茄头部中间的硬芯吃不动，要切掉。然后把番茄像切西瓜一样切成小块。

这个菜除了姜，还需要大蒜。大蒜的味道和番茄很搭配。用2瓣蒜切片备用。码肉后开始做。

  1. 锅烧干，放入少许植物油。如果家里有猪油更好，一起放；
  2. 放入姜片、蒜片，炒香后，番茄下锅炒一下；
  3. 当番茄炒出酱汁，能明显闻出香味后（3分钟左右），加水
  4. 汤烧开后放盐，然后加肉片；
  5. 2分钟快熟了，就放鸡精味精，盐度不够再放盐
  6. 炒番茄时已经放过油了，这里不再放油，直接出锅。撒上葱花。

酸菜肉片汤

超市直接买成品鱼酸菜，再买袋装野山椒就可以。

酸菜取出来挤干水分，切成小块。菜帮子部分用斜刀切成薄片，叶子展开切成小块。如果酸菜自带姜和辣椒，可以拿来直接用。需要注意姜不一定品质很好，可能含有很厚的木质层，需要把肉质层剥出来。

超市买的酸菜一般都很咸，需要把切好的酸菜放到盆里清洗2遍，把多余的盐分洗掉。攥干水分备用。

野山椒很辣，用2、3根就可以了，切成小段和酸菜放一起。多余的冻起来就行。泡椒水是很好的东西，不要扔掉，放一边备用。

然后再切一点姜片。也可以再来一点金针菇，酸菜汤搭配蘑菇很不错。把金针菇根部切掉，撕成小束，清洗干净备用。清洗很简单，简单冲一下就行。

  1. 锅烧干，放入油，有猪油更好一起放；
  2. 放几粒花椒、生姜爆香；
  3. 放入酸菜、野山椒，翻炒一分钟后加水，然后再倒入一勺野山椒水；
  4. 汤烧开后转小火，再慢煮2、3分钟，把酸菜的香味熬煮出来；
  5. 转大火，放入金针菇，盖上盖子焖煮一分钟；
  6. 酸菜、野山椒、野山椒水都有盐，所以不需要再额外加盐，直接放肉片；
  7. 放入一汤匙的白醋，仅仅依靠酸菜的酸度是不够的；再加入一点耗油；
  8. 放入味精、鸡精，这个汤的口味重，所以可以稍微给多一点。
  9. 炒酸菜时放过油了，不再加油，出锅前尝尝味道，盐度不够放盐、酸度不够加白醋；

酸汤类菜肴，用的是白醋，可千万不要用成陈醋了，味道不一样。

Q：是先放菜还是先放肉？

A：煮肉的时间就是2分钟，2分钟煮不熟的蔬菜，就先放蔬菜；很快成熟的蔬菜（各种绿叶菜），就先放肉。

 

炒肉公式

本节会学习三种风味的家常菜炒肉风味：豆瓣酱炒出的豆瓣风味、青椒炒出的青椒香、干辣椒炒出的胡辣香。

本节炒肉菜都需要提前腌制肉，这个步骤就不再复述了。腌过的肉下锅后粘在一起不容易打散，可以在肉上撒一圈食用油拌匀，这样肉下锅后可以轻松的滑散。

  1. 肉切好码味，加姜蒜、豆瓣酱，如果不爱吃豆瓣酱也可以不放，就变成清炒了
  2. 腌肉时准备配菜
  3. 炒菜，配菜容易熟就肉快熟时放，不容易熟就先把配菜炒到7、8成熟再和肉一起炒
  4. 调料

黄瓜炒肉

这个例子中，黄瓜比肉更容易熟

  提前腌肉；准备几瓣大蒜，切成片；掰掉一块生姜，清洗干净，先切3到4片姜片，然后切姜丝。姜切成丝后更出味。把切好的姜蒜和腌的肉放在一起。然后再取一勺豆瓣酱，也和肉放在一个容器备用。

  在家里炒菜，最好是把葱姜蒜、豆瓣酱和肉都放在一起，一起下锅炒。在饭店里，正常的步骤是先把豆瓣酱炒香，然后放入姜蒜，爆香后再放入准备好的肉片，全程旺火，一道菜1、2分钟就好了。但家里天然气火力太小了，按照饭店里的做法的话，锅里就始终保持一个低油温状态，炒菜会变慢，这样炒出来的肉又老又柴。一起放进去的话，可以让刚刚烧热的油直接给到肉，模拟饭店的旺火。

  炒菜选土黄瓜最好，最好选直溜的，更好切。实在买不到用普通黄瓜也可以。黄瓜清洗后去头去尾，然后竖着切成2半，每一半再单独切片，切片时刀可以斜一点，切出来的片更大。炒肉需要黄瓜在很短时间内成熟，所以黄瓜片切的要薄，1mm厚。用这个方法切两根黄瓜。

炒肉菜全程大火，并且放油不能小气，不然要么油烟味太大，要么颜色黑黢黢的。

  1. 锅烧干，倒油烧热，等油冒烟；
  2. 油冒烟后，放入几粒干花椒，不要等，直接把肉、葱姜蒜、豆瓣酱一起下锅，用锅铲滑散均匀受热。此时油温很高，可能会四处飞溅油滴，一定要迅速把肉滑散，把温度降下来；不断翻炒；
  3. 看不到红色的生肉，就代表有6、7成熟了，放入黄瓜。不要放早了，否则黄瓜拉低了锅中的温度，拉长了炒肉时间，会让肉变柴。
  4. 黄瓜开始打蔫的时候代表快熟了，可以放调料，此时用小火，放一勺生抽、味精、鸡精、一小点陈醋；这个不需要放盐了，码肉的时候放盐了，生抽、豆瓣酱也有盐；
  5. 开大火，和匀调料。出锅。

 

莴笋炒肉

这个例子中，肉比莴笋更容易熟。

  提前腌肉；准备几瓣大蒜，切成片；掰掉一块生姜，清洗干净，先切3到4片姜片，然后切姜丝。姜切成丝后更出味。把切好的姜蒜和腌的肉放在一起。然后再取一勺豆瓣酱，也和肉放在一个容器备用。

  这个菜的难点是处理莴笋，厚厚的皮处理起来很麻烦。选购莴笋的时候尽量选择平整的，太过粗大的不买，质地较老，很容易存在空心；太细的也不买，去皮后就啥也不剩了；带花的不买，莴笋开花说明莴笋已经非常老了。

  有的莴笋会带着莴笋尖买（顶部叶子），剥莴笋时需要先把莴笋尖取下来，莴笋尖最下面的叶子如果老了要提前取下来，然后从莴笋尖比较嫩的地方切断。莴笋尖很嫩，可以用来炒菜、下面条、煮汤。

  剥莴笋的常规方法就是左手握住莴笋根，用刀一点一点把木质层去掉，切记手指不要露头防止受伤。木质层吃不动，一定要清理干净。然后把根部老的地方切掉。最后用水简单清洗一下就好。邪修法就是用甘蔗去皮刀了，家里普通的去皮刀是切不动莴笋皮的。

  莴笋放在菜板上，稍微斜着切薄片。如果讲究一点也可以切菱形片，也是先把莴笋放到菜板上斜着放，然后切长段。然后依次把长段竖着放菜板上切片。黄瓜、胡萝卜、西葫芦、山药等都可以用这种方法切片。

  和黄瓜炒肉不同，莴笋不容易成熟，如果先放肉再放莴笋，那么肉就老了，所以要分两步来进行：

  1. 锅中烧干放油，油热后直接放入莴笋片，大火炒到7、8成熟，由青绿色转变为略带透明的翡翠色（一分半多就差不多了），直接出锅备用，这一步任何调料都不要放；
  2. 重新烧干放油，油冒烟后，放入几粒干花椒，不要等，直接把肉、葱姜蒜、豆瓣酱一起下锅，用锅铲滑散均匀受热。此时油温很高，可能会四处飞溅油滴，一定要迅速把肉滑散，把温度降下来；不断翻炒；
  3. 看不到红色的生肉，就代表有6、7成熟了，放入刚刚炒的莴笋片。
  4. 翻炒片刻，小火放入调料：生抽一勺、味精、鸡精、一点醋，调料和匀，尝一下咸度，合适就出锅；尝菜要尝瘦肉，肥肉不入味尝不出来，蔬菜如果盐度合适那肉一定咸了；

  

青椒炒肉

  提前腌肉；准备几瓣大蒜，切成片；掰掉一块生姜，清洗干净，先切3到4片姜片，然后切姜丝。姜切成丝后更出味。把切好的姜蒜和腌的肉放在一起。这道菜是青椒口味，就不需要放豆瓣酱了。

  青椒去籽，去籽方法请看【厨艺小百科】，也可以不去籽，直接把青椒把去掉。处理完的青椒用清水清洗2遍。青椒要切片，先从中间切成两半，然后随意切块，只要大小均匀就行。

  青椒肉质比较厚，属于不那么容易熟的蔬菜。

  1. 先开小火，把青椒慢煎几分钟，千万不要放油，不然油烟呛死人，这一步的目的是把青椒的水分去掉一些；大概五分钟左右，感觉煎出锅巴了，青椒打蔫了，放入少许盐继续翻炒半分钟左右，这样就解决了青椒不入味的问题，然后出锅；
  2. 锅清洗干净，烧干放油，大火，油冒烟后，放入几粒干花椒，不要等，直接把肉、葱姜蒜一起下锅，用锅铲滑散均匀受热。此时油温很高，可能会四处飞溅油滴，一定要迅速把肉滑散，把温度降下来；不断翻炒；
  3. 看不到红色的生肉，就代表有6、7成熟了，放入刚刚炒的青椒；
  4. 翻炒片刻，小火放入调料：生抽两勺（没有豆瓣酱，生抽可以多放）、味精、鸡精、一丢丢的盐、一点醋，调料和匀，尝一下咸度，合适就出锅；

 

苦瓜炒肉

  提前腌肉，这道菜炒的时候是不放生抽的，因为会让苦瓜变丑，所以腌肉时可以先放2勺生抽；准备几瓣大蒜，切成片；掰掉一块生姜，清洗干净，先切3到4片姜片，然后切姜丝。姜切成丝后更出味。把切好的姜蒜和腌的肉放在一起。这道菜还要放一点青椒，这个选择辣一点的美人椒。青椒先清洗，把后面的把去掉，然后切滚刀块。青椒是配角，用2、3个就行了。也可以不放辣椒，就变成了清炒风味。把辣椒也和肉放一起。

  苦瓜是很好买的，很少翻车。要注意变黄的苦瓜是完全成熟的样子，这种苦瓜苦味降低，甚至发甜，但口感很面。是否喜欢吃这个就因人而异了。

  苦瓜清洗一下，去头去尾。然后竖着切成两半，除去中间的瓜瓤（不方便就用勺子），然后横放在菜板上切片，2mm左右即可。

  苦瓜属于不易成熟的，所以需要先炒蔬菜。

  1. 锅中烧干放油，油热后直接放入苦瓜片，大火炒到7、8成熟。大部分蔬菜都是越炒水越多，但苦瓜本身水分就少，为了防止苦瓜变干瘪，翻炒30秒左右要倒一小口水进去，这样炒出来的苦瓜比较滋润，看到苦瓜基本变软（整体2分钟左右）就可以出锅了，这一步任何调料都不要放；
  2. 锅清洗干净，烧干放油，大火，油冒烟后，放入几粒干花椒，不要等，直接把肉、葱姜蒜、辣椒一起下锅，用锅铲滑散均匀受热。此时油温很高，可能会四处飞溅油滴，一定要迅速把肉滑散，把温度降下来；不断翻炒；
  3. 看不到红色的生肉，就代表有6、7成熟了，放入刚刚炒的苦瓜；
  4. 翻炒片刻（10秒左右），小火放入调料：盐、味精、鸡精，不再放生抽和醋了，尝一下咸度，没问题就出锅；

 

西兰花炒肉

  提前腌肉；准备几瓣大蒜，切成片；掰掉一块生姜，清洗干净，先切3到4片姜片，然后切姜丝。姜切成丝后更出味。把切好的姜蒜和腌的肉放在一起。

  这道菜做成糊辣口味的，需要用到干辣椒。市面上有很多品种的干辣椒。家里做饭建议选择香味更高、辣度适中的品种，如“新一代”、“二荆条”、“线椒”、“秦椒”、“丘北辣”等。另外一些辣度很高的品种，如“小米辣”、“子弹头”、“七星椒”、“石柱红”、“印度椒”等适合变态辣爱好者选择。

  选取3~4个干辣椒切成段放在一边备用。

  西兰花拿到后是一整个，需要先切成小朵，从茎的位置切。叶子去掉不要。切下来的小朵需要再次切小一点，一朵切4个就行。一整颗没必要都切下来，还是很多的，可以留下备用，冰箱里能存一周。切完后留下的大粗茎也可以吃，很脆，但需要像剥莴笋一样把木质层去掉，然后切成薄片。切完后用清水淘洗两遍。

  西兰花属于不宜成熟的，需要先炒菜再炒肉，西兰花下锅前需要先焖煮一下，操作比较麻烦。不过有个简单粗暴的方法，直接过水。

  这道菜是糊辣香气，把辣椒煎到半糊的状态就会有糊辣的香气。难点在于煎的不够辣椒香气出不来，煎过头辣椒就全糊了。

  1. 起锅烧水，水开后直接放入西兰花，煮一分钟出锅；出锅后过凉水，防止扎堆的西兰花过熟，也可以让西兰花更爽脆；滤干水份备用；
  2. 大火烧干锅，倒油，油热后倒入干辣椒段；
  3. 油很热，等几秒钟，干辣椒由红变黄后倒入肉片，肉片滑散，不断翻炒；
  4. 翻炒1分半多看到肉断生后，放入西兰花，西兰花已经熟了，不需要炒太久，翻炒片刻就好；
  5. 关小火，放调料。这里可以放花椒粉（也可以选择在一开始的时候煎干花椒）、生抽2小勺、盐、味精、鸡精、一小勺醋。调料和匀出锅；

 

葱爆肉

  提前腌肉；准备几瓣大蒜，切成片；掰掉一块生姜，清洗干净，先切3到4片姜片，然后切姜丝。姜切成丝后更出味。把切好的姜蒜和腌的肉放在一起。

  3~4个干辣椒切成段。

  这道菜的配菜是大葱。大葱当作配菜时，需要买那种粗大的，吃起来更嫩。选择葱白多葱叶少的更实惠，因为葱叶一般用来腌鱼腌肉，但不食用。

  大葱三根，先切掉根部，然后剥掉表面失去水分的干皮，冲洗一下。然后斜刀切成薄片。

  1. 四档大火，烧干倒油，油热放入干花椒粒、干辣椒段；
  2. 略等几秒，辣椒由红变黄后倒入肉片，肉滑散；
  3. 肉没有红色断生后，放入切好的大葱，翻炒。大葱没啥水分，越炒乐越干，中途可以加一点点水，炒出来的菜更滋润；
  4. 看到大葱打蔫了，关小火放调料：生抽2小勺、盐、味精、鸡精，开大火和匀后放入一点点陈醋，和匀出锅；

 

平菇炒肉

主料：瘦肉

辅料：平菇

调料：盐、淀粉、料酒、胡椒粉、鸡精、生抽、干花椒、生姜、大蒜、食用油

  平菇购买时，挑选叶片颜色偏墨绿色，形状圆润的，吃起来会更脆嫩。叶片完全打开的吃起来比较绵软，不推荐购买。

  提前腌肉；准备几瓣大蒜，切成片；掰掉一块生姜，清洗干净，先切3到4片姜片，然后切姜丝。姜切成丝后更出味。把切好的姜蒜和腌的肉放在一起。

  平菇先切掉根部，然后撕小一点方便食用。撕完后用清水冲洗，洗的时候力气不要太大，否则容易把蘑菇洗碎。平菇没有什么泥沙，稍微冲洗两遍就行。沥干水分备用。

  大多数的蘑菇都要认为是不容易熟的菜，蘑菇一定要充分加热，否则容易食物中毒。需要先把蘑菇炒熟。

  1. 锅烧干倒油，油热后倒入蘑菇，用三档火，火太大容易把蘑菇炒糊，火太小蘑菇里的水分就流出来了，水分太大会让最后的成菜不清爽。蘑菇的水分很多，等水分快炒干，蘑菇打蔫变软时就代表快成熟了，加小半勺盐进来，让蘑菇有底味；盐和匀后把蘑菇盛出来；
  2. 锅洗干净，烧干倒油，四档大火，油热放入干花椒，稍微炸一下就放肉，把肉滑散，不断翻炒；
  3. 肉没有红色生肉基本断生后，放入炒好的蘑菇，稍微翻炒一下；
  4. 关小火放调料：三勺生抽、鸡精，蘑菇本身就有鲜味成分，可以不放味精，开大火和匀；尝尝咸淡，不够加盐，够了直接出锅；

凉拌菜

拍黄瓜

主料：黄瓜两根；

调料：生姜、大蒜、盐、味精、鸡精、生抽、陈醋、花椒油、芝麻油

  1. 黄瓜洗净，不用去皮。把尾部的蒂去掉，头的部分先留着；
  2. 左手握住头部，右手持刀往下拍，使劲拍，拍碎一点容易入味（也不要太碎，不然就失去口感了），彻底拍碎后去掉头部。
  3. 刀斜着45°切成小块，间距2cm左右，放入盆中；
  4. 要2瓣大蒜，一点生姜，混合切成沫，放入盆中；
  5. 放入调料：一勺盐，半勺味精、半勺鸡精、2勺生抽、1勺陈醋、半勺花椒油、半勺芝麻油
  6. 搅拌均匀

凉拌金针菇

主料：金针菇一把

调料：盐、味精、白糖（白砂糖即可）、生抽、陈醋、花椒油、芝麻油、生姜、大蒜、红小米椒、辣椒油

金针菇根部比较老，要切掉一部分。撕成小束。淘洗两遍，金针菇没有什么泥沙，稍微清洗即可。

  1. 锅中烧水，水开后下入金针菇，大概煮3分钟基本熟透，倒出来后过凉水，滤干水份备用；
  2. 用小碗准备调料汁：一勺盐、一勺味精、一勺白糖、三勺生抽、两勺陈醋、几滴芝麻油、几滴花椒油、两勺辣椒油、一点姜蒜末、2到3个小米椒的辣椒碎；
  3. 金针菇装盘，把料汁淋在金针菇上。
  4. 加一点葱花点缀；

凉拌豇豆

主料：豇豆一把

调料：盐、味精、白糖、生抽、陈醋、花椒油、芝麻油、生姜、大蒜、红小米椒、辣椒油

豇豆有两种：绿色的和紫色的。绿色的豇豆口感爽脆，紫色豇豆口感偏面。豇豆细一点的、捏起来硬邦邦的就比较嫩，很大根的，捏起来往下塌的就比较老。

豇豆择菜和四季豆类似。找到尖的那头，逆着把头撕下来，然后从刚刚撕完筋的一侧掐断让另一侧的筋露出来；把另一侧的筋掐掉，再掐断，循环往复。择菜时注意黑点，这个是虫眼，这一节掐掉不要。

豇豆本身没有什么筋，如果豇豆本身品质不错，可以直接用刀切成5cm左右的段。

择好的豇豆淘洗2遍，滤干水份备用。

经典家常菜

炝炒莲花白

食材：圆白菜、2g花椒、7g干辣椒、22g生抽、20g米醋、2g盐、1g味精、5g糖

莲花白是四川的一种菜，在家做的时候，就买那种松弛的圆白菜就行。买回来的圆白菜从中间切2半，把中间的杆去掉不要。这道菜很注重火候，杆和叶成熟时间不一样，所以只要叶子。把叶子用手撕成小片。圆白菜一定不要超过家里锅的高度，家中火不够大，菜太多温度下降的特别快，出菜影响口感。

还是因为火候很重要，所以要把碗汁兑好。生抽、米醋、糖、味精、盐按照前面的克重来加。

  1. 锅中倒油，烧热后放入花椒，关小火炸香；
  2. 倒入一小点凉油，把干辣椒倒进锅中炸香；
  3. 辣椒变棕红色后，把圆白菜放进锅中，全程开大火翻炒；
  4. 菜变颜色就可以沿着锅边倒入碗汁，翻炒一下出锅；

 

家常豆腐

这道菜先把豆腐煎出金黄的表皮，然后再重新烹调调味。

主料：豆腐一块。一般用嫩豆腐，表面煎出酥皮了内部还是嫩的，但下锅煎的时候新手很可能把豆腐弄碎，所以新手可以用老豆腐

辅料：猪瘦肉或者牛瘦肉一小块

调料：盐、豆瓣酱、生抽、料酒、胡椒粉、味精、鸡精、淀粉、生姜、大蒜、蒜苗、油

备料：

  1. 取一块豆腐，先切2半，然后再切1cm厚的片；放一边备用；
  2. 把肉洗净后切小块，然后剁成肉沫，放一边备用；
  3. 2瓣大蒜、一小块生姜，都切成颗粒；
  4. 两颗蒜苗，根洗净后切成段：根部斜刀切，叶子直接切，放一边备用；
  5. 一勺淀粉、一勺水，搅拌均匀做成水淀粉

把豆腐煎一下，剪到两面金黄，煎过的豆腐表皮失去水分孔隙变大，更好吸收调料:

  1. 锅烧干后，二档火，放薄薄的一层油，再均匀的撒一些盐，既可以防止豆腐粘锅，也可以让豆腐提前入味；晃一晃锅底，让锅底均匀铺满油；
  2. 依旧二档小火，用筷子轻轻夹起豆腐，均匀铺在锅底，拜访紧凑一下。如果一次煎不完可以多次来；全程二档火，慢慢煎。煎的时候时不时晃动锅底，防止粘锅；没隔一分钟都可以晃一下；
  3. 如果豆腐边角变黄，就可以翻面了；
  4. 第二面也变黄了，再翻个面复煎一下；2分钟左右再翻个面；然后出锅；

最后可以重新烹饪调味：

  1. 2档小火，锅不用洗，补一点油，然后放入一勺豆瓣酱，慢慢翻炒；豆瓣酱炒香后，放入姜、蒜；
  2. 姜蒜翻炒10秒，就放入肉沫，用锅铲尽快把肉沫散开，不停翻炒；
  3. 肉沫炒散后，放入一点胡椒粉，一小勺料酒，继续翻炒片刻，把肉沫水分炒干；
  4. 把豆腐放进来，加水没到豆腐8分满（别加太多，这个不是豆腐汤），然后开大火，把豆腐弄匀后加入2勺生抽，弄均匀后，盖上锅盖，继续用2档小火炖煮；
  5. 水开后再煮2分钟，打开盖子开始调味。先尝一下锅里的汤，如果盐度合适就不用加盐，否则要补一点盐，加一点鸡精、味精，调料和匀，动作轻一点别把豆腐弄碎了；
  6. 切好的蒜苗倒入锅中，翻炒；
  7. 把水淀粉搅散，倒入锅中勾芡，可以让汤汁变得浓稠，不停搅拌20秒后出锅；

 

麻婆豆腐

主料：豆腐一块，老豆腐嫩豆腐都可以，老豆腐吃起来更香、嫩豆腐口感嫩滑

辅料：猪/牛瘦肉一小块

调料：豆瓣酱、豆豉、盐、生抽、味精、鸡精、辣椒粉、蒜苗2颗、淀粉、花椒粉、食用油

要把豆腐切成拇指大小的方块，切小一点方便入味。先横着慢慢切，正常大小的豆腐切两刀，变成三个厚片就行，每层1.2厘米厚。接着码放整齐，竖着切，切成大小统一的小方块。切好都放一边备用。

一小块瘦肉，洗净后切成肉沫。放一边备用。

两颗蒜苗，洗净后去掉根部。茎的部分用刀拍破，然后和叶子一起切成1cm长的小段。放一边备用。

拿出几颗豆豉，稍微改小，放一边备用。

取2大勺淀粉，加小半碗水，和匀做成水淀粉。

  1. 锅中加冷水，水要多一点，把豆腐倒进来，开大火焯水。焯水的目的是去除豆腐的豆腥味。需要加入2勺食盐，让豆腐有底味。大火把水烧开后，再转中小火煮一分钟；煮完后把豆腐倒出来沥干水分备用；
  2. 锅烧干、倒油，中小火，倒入一大勺豆瓣酱；豆瓣酱炒香后倒入豆豉、2大勺辣椒粉，火一定不要大，不然辣椒就炒糊了；
  3. 辣椒炒10来秒，出香味后倒入肉沫翻炒，炒散后撒一小勺胡椒粉、一小勺料酒，然后再炒30秒左右；
  4. 倒入清水，能刚好末过豆腐，转大火把水烧开；
  5. 水开后转中小火调味：4勺生抽，和匀时尝尝咸度，此时汤的咸度要和日常吃菜的咸度一样，不够就补盐，汤要咸一点，否则一会煮豆腐没味；
  6. 把豆腐倒入锅中，锅铲推散推均匀，用二档小火慢慢煮，让豆腐吸收味道。煮的时候用锅铲时不时铲一下锅底，免得粘锅；
  7. 看时间，大概4~5分钟，锅里的水还剩一半时，放入一勺鸡精、一勺味精，和匀。需要注意，由于锅里全是豆腐，所以大概豆腐露出1/3的时候，汤就是还剩一半的量；千万不要等豆腐露出一半了再放调料，此时汤就很少了；
  8. 把水淀粉抓散，倒入1/3，用锅铲背部不停的轻轻地推，和匀；等半分钟左右淀粉熟了，再倒剩下的1/3，再不停的推半分钟；
  9. 倒入切好的蒜苗，再把剩下的水淀粉全部倒进了，不停的推半分钟。淀粉分三次加的原因是加入的淀粉会让锅里的汤汁一次比一次浓稠，淀粉可以更好的包裹食材。
  10. 出锅，表面轻轻撒一层花椒粉；

二、刀工

做好一道菜，七分靠刀工，三分靠炉工。

持刀

常见的错误的持刀姿势：

  • 食指按在刀背上；
  • 拇指按在刀背上；
  • 只握刀把

正确的握刀方法，需要拇指和食指扶着刀身，这样可以紧紧的握住刀，切起菜来也非常灵活。

切块

南瓜/冬瓜汤

买来的南瓜皮很厚，需要用刀来切。一个南瓜切掉一半后，像刨子一样刮掉皮。然后再切一半（1/4）后，把南瓜瓤去掉。

切菜就是左手和右手的配合，左手起到两个左右：

第一就是支撑作用，握住食材后，用中指的第一个关节支撑刀，手指往里面握。刀抬起的高度永远不要超过中指的第一个关节。千万不要把手指放平来切菜，很容易切到手，且没有效率。刚开始学的时候，手掌不要悬空，要么贴着案板，要么贴着食材。，牢牢控制住食材，防止食材到处跑。

第二个作用就是量距离，要切多大，左手就要留出多大的位置。切一块后左手往后退再切。

把南瓜切成块。

冬瓜同理，先用刀去皮。切成两半后把瓤去掉。然后按照切南瓜的样子，左手配合右手切。

切蔬菜就是一切到底，不要考虑什么推、拉、锯什么的都不要管。

切蔬菜时食材很容易沾刀，有一个小窍门就是刀稍微往右边（外边）倾斜一点点，这样切菜后会往右边掉，就不会粘在刀上了。

切完南瓜，再切一点小葱，切成葱花，2~3毫米就行。切姜片，1毫米后左右。一个汤中准备3、4片即可，有提鲜增香的作用。

  1. 锅中加水，你用什么容器来装菜，就用什么容器来量需要多少水，水到容器的七成或八成；然后锅中放入南瓜、3、4片姜片，盖上盖子，直接四档大火把水烧开；
  2. 转2档小火慢煮，约10分钟；判断有没有煮好就用筷子戳一下南瓜，没有阻力就说明煮好了；
  3. 煮好后加入调料：盐、鸡精、味精、少许食用油；
  4. 出锅后加入少许葱花；

用这个方法可以做南瓜汤、冬瓜汤、芋头汤之类的。

当出锅后，还可以继续加工，放入锅中二次四档大火烧开，开锅后放入羊肉片，打去浮沫煮2、3分钟即可出锅。

切片

焖炒冬瓜片

一片冬瓜，切一半，去皮去瓤。

切片和切块一样的手法，但切片一定要注意均匀，1mm厚左右即可。如果不均匀，煮菜时相同的时间有的是生的，有的都煮烂了。

刚开始不要着急，慢慢来。后期熟练的时候，可以切三退一或者切五退一，先留出三片(五片)位置，切完后再后退，这样可以找到饭店大厨切菜的感觉。

这道菜要用到两个新调料：

第一个是耗油。耗油有一种细腻的咸鲜感，起到提味增鲜的作用；第二个是生抽，起到提味、增香、上色。

  1. 大火起锅烧油，放入切好的冬瓜，翻炒2分钟；
  2. 放入一丢丢水，防止冬瓜糊锅；
  3. 三档火候盖盖子煮一分钟。冬瓜本身含水，但需要煮一会才能把自身的水分释放出来，所以需要提前加一点点水，算是“引子”；
  4. 一分钟后，把面上的冬瓜翻炒到下面，地下的冬瓜翻上来，让食材受热均匀，再焖煮一分钟；
  5. 放入耗油、少许生抽，和匀。生抽不易过多，否则颜色太深；
  6. 放入盐、味精、鸡精。耗油和生抽都带盐，所以不用放太多。
  7. 出锅

切丝

青椒炒土豆丝

土豆先去皮，然后清水洗干净。先把土豆切成片，然后再切成丝。

土豆整体一面宽、一面窄。先在宽的那面切2、3刀，大概2mm厚，这样可以切出一个平面来。接下来把这个平面当作底，这样土豆就比较稳定，不会滚来滚去。然后就可以切片了。

切完后，把之前切下来的那几片放在前面，然后用刀轻轻的拍均匀拍散开。然后就可以切丝了。只要切片切的匀，切丝就均匀。

切好的土豆丝用清水浸泡，防止变色。

炒之前要用清水淘洗以下，洗去土豆上的淀粉，这样炒出来的土豆丝就不会黏黏糊糊的。沥干水分备用。然后把青椒切成丝，两瓣蒜切成片。

  1. 大火锅烧干，放油；
  2. 油热就放蒜，然后马上放入土豆丝、辣椒丝。
  3. 大火慢炒，让食材充分受热。（家里的火不能和饭店里的火比，所以家中都是大火慢炒）；
  4. 大概炒2分钟，土豆丝变透明了，可以放入盐、味精、鸡精。使劲和匀；
  5. 出锅；

切丁

扬州炒饭

原料：黄瓜、胡萝卜、火腿肠、鸡蛋、小葱、生姜、冷米饭。

黄瓜去头去尾。黄瓜需要切成6mm厚的丁，所以先要切成6mm厚的片，要竖着切，不要横着切；切完后再把黄瓜切成丝，也是6mm宽度；最后把丝码放整齐，按照6mm厚切成丁。

胡萝卜去掉根部，和黄瓜一样切6mm厚的片，竖着切。然后切成6mm的丝；然后切丁。

火腿肠重复操作，第一步切片也竖着切。

把这些原料都码放到一个盘子里。

接下来切姜末。先切一点薄片，不用太多；然后把姜片切成细丝，然后再切洗沫。其实就是切丁，只不过很细小。

最后切葱花。直接切成很小的段就行。2、3mm左右即可。

取一个碗，打入两个鸡蛋，稍微加入盐，一定不要加太多，因为之后炒饭时还要加盐，搅匀鸡蛋，蛋清和蛋黄混合就行，不用打太散。

  1. 大火烧干锅，加入油。 先煎鸡蛋，所以一定要等油足够热，油热了鸡蛋才能松软酥香
  2. 倒入鸡蛋，两面煎的差不多了就捞出来；
  3. 用刚刚的油煎切好的食材丁，翻炒半分钟后把姜末放进去一起翻炒半分钟；
  4. 倒入米饭、鸡蛋。鸡蛋用锅铲弄碎；慢慢翻炒一分钟；
  5. 放入调料，蛋炒饭放盐能稍微尝出咸味即可。可以用手把调料撒匀，防止一嘴咸一嘴淡，然后疯狂翻炒。
  6. 最后放入葱花，继续疯狂翻炒；
  7. 出锅。

切沫

蒜蓉油麦菜

取三棵油麦菜。如果油麦菜底部发红代表不新鲜，切掉不要。把叶子撕下来，不用切，放在一起用拳头拧，凝成拳头大小的段。油麦菜的颈很好吃，不要扔掉，可以切成薄片。把菜淘洗一下，然后滤干水份。

直接取半头蒜，大概5-6瓣。蒜头前面很硬，要切掉。

蒜末如果直接用菜刀胡乱切，会把蒜弄的到处都是，很难打扫。可以先把蒜切小一点，然后胡乱剁。有一种切法是用另一只手拿着菜刀的另一头，左右摇摆来回切。

  1. 锅烧干放油；润一下锅；
  2. 看到锅开始冒烟后，放入蒜末，稍微滋滋几下就好，然后马上放入油麦菜。
  3. 翻炒1、2分钟，等叶子炒蔫巴了，放入盐、味精、鸡精，和匀出锅。

滚刀块

滚刀块不算太常用，在炖、闷的菜品里用的比较多，可以用这种切法切土豆块、窝笋块、萝卜块。

素炒胡萝卜

原料：4、5根胡萝卜、三瓣蒜。

胡萝卜清洗，去头去尾。

滚刀块就是滚着切。先在一头斜着切一刀，然后胡萝卜往我们这边滚90°，再斜着切一刀，厚度要和之前的基本一致。循环往复。

大蒜去皮切片。

  1. 锅烧干放油，放入蒜片煎几秒钟；
  2. 放入切好的胡萝卜，再煎一分钟；
  3. 加水，大概淹没食材三分之一。因为胡萝卜切的滚刀块不容易熟，需要盖上锅盖焖煮一段时间，用二档小火焖煮5分钟。
  4. 打开锅盖，翻炒一下，让成熟度均匀。胡萝卜不容易入味，需要提前放盐。放入盐后再翻炒一下。然后盖上锅盖继续焖煮3~4分钟；如果水快没了，可以补一点，防止糊锅。
  5. 用锅铲戳胡萝卜，如果能轻松戳动，就代表达到了我们需要的成熟度。胡萝卜煮耙且没有多余的汤汁，就可以放鸡精和味精，如果有多余的汤汁，开大火收汁。
